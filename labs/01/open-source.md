## 1. Licence

Source: [LICENSE](https://github.com/python/cpython/blob/main/LICENSE)

- **Licence:** Python Software Foundation License Version 2 (PSF License). Code examples in the documentation are also available under the Zero-Clause BSD licence (since Python 3.8.6).
- **Permissive or copyleft:** permissive. The licence file itself explains that, unlike the GPL, Python's licences let you distribute a modified version without making your changes open source.
- **If I copy code, I must:** keep the PSF licence agreement and the copyright notice "Copyright (c) 2001 Python Software Foundation; All Rights Reserved" (§ 2). If I share my own version based on Python, I must add a brief summary of my changes (§ 3).

## 4. People

Sources: [Contributors](https://github.com/python/cpython/graphs/contributors) · [PEP 13 – Python Language Governance](https://peps.python.org/pep-0013/)

- **Contributors:** 3,758 (as of 30.10.26)
- **Who decides:** Core developers review and merge pull requests. The Steering Council, five people elected by the core developers, has the final say on disputed decisions and the direction of the language.

## 5. Money

Sources: [Sponsor button on the repository](https://github.com/python/cpython) · [PSF donations](https://www.python.org/psf/donations/python-dev/) · [LICENSE](https://github.com/python/cpython/blob/main/LICENSE)

- **Donations:** The repository has a *Sponsor* button. It leads to GitHub Sponsors for the Python organisation and to a donation page of the Python Software Foundation.
- **A foundation:** The Python Software Foundation (PSF) is a non-profit organisation that owns Python's intellectual property and collects the money.
- **Volunteers:** The LICENSE file thanks the many outside volunteers who have worked on Python.
